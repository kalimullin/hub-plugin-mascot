# Маскот — плагин Agents Hub

Пиксельная сова в шапке боковой панели (строка «Хаб сессий», справа) показывает состояние всего флота одним взглядом:

- **ждёт вас** — у какой-то сессии вопрос, запрос инструмента или она упала: подпрыгивает, рядом «?»;
- **работает** — хоть одна сессия занята ходом: глаза бегают;
- **спит** — все свободны или спят: глаза закрыты, уплывают «z».

Подсказка при наведении — сводка («Работают 1 · ждут вас 1 · спят 2»). Клик ничего не делает. При «уменьшить движение»
стоит первый кадр.

Место — `sidebar.header` (API плагинов 1.5). На хабе с API ниже 1.5 сова садится в подвал боковой панели.

## Поставить

«Настройки» → «Плагины» → найти «mascot» или вставить ссылку на этот репо → «Проверить и поставить».

## Свой персонаж

Замените `mascot-sprite.js`: в шапке файла — контракт (палитра, кадры ASCII-картами для трёх состояний, длительность,
знак рядом). Размер карты и число кадров — любые; `main.js` и `mascot.css` трогать не нужно.
